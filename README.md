# jacket-image — mp3 / m4a のカバーアート自動付与

PC 内の `.mp3` / `.m4a` を再帰的に走査し、**カバーアート（ジャケット画像）が入っていないファイルだけ**を対象に、
曲情報から画像を自動で探して埋め込むコマンドラインツールです。

- APIキーの登録は不要（iTunes Search API を利用、見つからなければ MusicBrainz / Cover Art Archive）
- 外部ライブラリは `mutagen`（＋画像プレビュー用に任意で `pillow`）だけ。HTTP は Python 標準ライブラリ
- **候補画像を見ながら Enter で確定 / n で次の候補 / k でキーワード入力**する対話モードあり
- Windows / macOS / Linux で動作

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

### 対話モード（画像を見て 1 件ずつ確定する）— おすすめ

```bash
python add_cover_art.py "D:/Music" -i
```

候補画像を 1 枚ずつ表示し、キー入力で決めます（入力後 Enter）。

| キー | 動作 |
| --- | --- |
| **Enter** | この画像で確定して埋め込み |
| **n** | 次の候補を表示（候補が尽きたら自動でキーワード入力へ） |
| **k** | 検索キーワードを自分で入力して再検索 |
| **s** | このファイルは飛ばす |
| **v** | OS 標準の画像ビューアで開く（このウィンドウだけは手動で閉じてください） |
| **q** | 終了（そこまでの結果は保存されます） |

**同じアルバムのファイルは最初の 1 回だけ聞かれます。** 一度確定すれば、そのアルバムの残りの曲には
同じ画像が自動で付きます（1 曲ずつ確認したい場合は `--ask-every-file`）。

#### 画像の表示方法（`--preview`）

| モード | 動作 |
| --- | --- |
| `window` | **ウィンドウを 1 枚だけ作り、候補ごとに中身を差し替えます。** 曲数がいくら多くてもウィンドウは増えず、処理の終了時（中断・Ctrl+C 含む）に自動で閉じます |
| `terminal` | **ウィンドウを一切開かず**、ターミナル内に画像を文字（半角ブロック＋24bit カラー）で描画します |
| `none` | 画像は出さず、アーティスト名・アルバム名・URL などの文字情報だけ |
| `auto` | 既定。`window` → `terminal` → `none` の順に、使える方式へ自動で切り替え |

```bash
python add_cover_art.py "D:/Music" -i --preview terminal --preview-width 60
```

ウィンドウ表示・ターミナル表示のどちらにも Pillow が必要です（`pip install pillow`）。
入っていない場合は自動的に `none`（文字情報のみ）になります。

### 全自動モード

確認せずにまとめて処理します。まずは **`--dry-run`** で結果を確認するのがおすすめです
（ファイルは一切変更されません）。

```bash
# 1. 変更せずに結果だけ確認
python add_cover_art.py "D:/Music" --dry-run

# 2. 数件だけ試す
python add_cover_art.py "D:/Music" --limit 10 --backup

# 3. 問題なければ全体に適用
python add_cover_art.py "D:/Music" --backup --report report.csv
```

macOS / Linux の例:

```bash
python3 add_cover_art.py ~/Music -i
```

## 動作の流れ

各ファイルについて、次の順に処理します。

1. **既にカバーアートがあればスキップ**（`--force` を付けると上書き）
2. 曲情報を取得
   - タグ（アーティスト / アルバム / 曲名 / アルバムアーティスト）
   - タグが無ければファイル名（`01 - Artist - Title.mp3` などを解析）と親フォルダ名（アルバム名の推定）
3. 画像を探す
   - 同じ（または親）フォルダの `cover.jpg` / `folder.jpg` / `front.png` など … `--no-local` で無効化
   - iTunes Search API（アルバム検索 → 曲検索の順）
   - MusicBrainz で該当リリースを検索し、Cover Art Archive の表ジャケットを取得
4. **一致度チェック** — 検索結果のアーティスト名・アルバム名と手元の情報を比較してスコア化し、
   `--min-score`（既定 0.6）未満なら「別のアルバムの画像」を貼らないよう見送ります
   対話モード（`-i`）ではこの足切りをせず、**候補をスコア順に並べて自分で選びます**
5. 画像を検証（JPEG / PNG のマジックバイトとサイズ）してから埋め込み
   - mp3 … ID3v2.3 の `APIC`（front cover）。v2.3 で保存するので Windows のエクスプローラーでも表示されます
   - m4a … MP4 の `covr` アトム

同じアルバムのファイルは 1 回の検索結果を使い回すので、アルバム単位ではほぼ 1 リクエストで済みます。
API への負荷を避けるためレート制限（iTunes 0.4 秒間隔 / MusicBrainz 1.1 秒間隔）を入れています。

## 主なオプション

| オプション | 説明 |
| --- | --- |
| `-i`, `--interactive` | 候補画像を見ながら 1 件ずつ確定する |
| `--preview MODE` | 表示方法 `auto` / `window` / `terminal` / `none`（既定 auto） |
| `--preview-width N` | `terminal` 表示の横幅（文字数、既定 44） |
| `--candidates N` | 1 回の検索で集める候補数（既定 8） |
| `--ask-every-file` | 同じアルバムでも 1 ファイルずつ確認する |
| `--dry-run` | ファイルを変更せず、何をするかだけ表示 |
| `--force` | 既にカバーアートがあるファイルも上書き |
| `--backup` | 書き込み前に `.bak` を作成 |
| `--size 600` | 取得する画像サイズ（正方形ピクセル、既定 600。1200 なども可） |
| `--country JP` | iTunes ストアの国コード（既定 JP） |
| `--min-score 0.6` | **全自動モードで**採用する最低一致度。誤った画像が付くようなら 0.75 程度に上げる（対話モードでは自分で選ぶので使いません） |
| `--no-local` | フォルダ内の `cover.jpg` 等を使わず必ず Web から取得 |
| `--offline` | Web を使わず、フォルダ内の画像だけで付与 |
| `--save-folder-jpg` | 埋め込みに加えてフォルダにも `cover.jpg` を保存 |
| `--report report.csv` | 処理結果を CSV に出力（Excel でそのまま開けます） |
| `--limit 10` | 処理件数の上限（動作確認用） |
| `--no-recursive` | サブフォルダを辿らない |
| `--quiet` | 1 件ごとの表示を抑える |

## 注意点

- **タグもファイル名も手がかりが無いファイル**（`track01.mp3` など）は特定できないため見送られます。
  CSV レポートの `not-found` / `no-metadata` を見て、必要なら先にタグを整えてください。
- 全自動モードは自動判定である以上、**別版・ベスト盤の画像が付く可能性はゼロではありません**。
  確実に正しい画像を付けたい場合は対話モード（`-i`）を使ってください。
  全自動で行うなら `--dry-run` と `--backup`、心配なら `--min-score` を上げて運用してください。
- 取得した画像は各サービスの著作物です。個人の手持ちライブラリの整理用途に留めてください。
- iTunes Search API / MusicBrainz は公開 API です。大量のファイルを一度に処理すると
  一時的に応答が返らなくなることがあります（その場合は自動でリトライ・スキップします）。

## テスト

```bash
python -m unittest discover -s tests -v
```

ネットワークへは接続せず、合成した最小の mp3 / m4a ファイルと API 応答のスタブで検証します（53 件）。
対話モードは入力を台本化したスタブ UI で、キー操作どおりに動くかを確認しています。

| --- | --- |
| `add_cover_art.py` | 本体（検索・一致度判定・埋め込み・対話モード） |

| `tests/` | テスト一式（ネットワーク不要） |
